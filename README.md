# NYC Tenant Compass

## Overview

NYC Tenant Compass helps tenants quickly determine whether their apartment may be rent stabilized by searching their address. The app provides clear, easy-to-understand results and directs users to trusted housing resources.

## MVP Goal

Build the simplest product that allows a tenant to:

- Enter an NYC address
- Search for rent stabilization information
- View a clear result
- Learn the next recommended step

## Core Interaction

The primary interaction is an address search. A tenant enters an NYC address, clicks Search, and receives a plain-language result.
